레퍼런스에서 가져온 원칙

  • 🌙 밤하늘 위에는 밝은 HUD: 어두운 반투명 + 얇은 금테 대신 크림·화이트 바탕 (동숲, 블루 아카이브)
  • 🧱 입체감은 테두리 선 대신 아래쪽 단색 그림자 0 4px 0 + 누르면 쑥 들어가기 (스플래툰, 폴가이즈)
  • 💊 버튼·상태창은 알약/동그라미, 아이콘은 크게 (브롤스타즈, 클래시 로얄)
  • 🏷️ 팝업 제목은 창 위로 튀어나온 명패, 탭은 큼직한 둥근 탭 (쿠키런 킹덤, 카트라이더)
  • 🧹 버튼 수 줄이기: 독 12개 → 6개 + 더보기, 반응 10개 → 버튼 1개로 접기
  • 🪀 팝업은 통통 튀는 스프링 등장 (지금도 있음, 유지)
