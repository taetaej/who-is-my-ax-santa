# 📻 AX 캐롤 라디오 곡 폴더

여기에 음원 파일(mp3·m4a·ogg·wav)을 넣으면 🔥 불멍 회의실 라디오에 자동으로 들어가요.

- **파일 이름 = `번호 제목 - 작곡자`.** 번호로 순서를 정해요. 예: `01 2026 Christmas Carol - 김민지.mp3`, `02 눈 오는 AX - 서보라.mp3`
- 작곡자를 빼면 제목만 나와요.
- **썸네일**: 곡과 이름이 똑같은 그림(jpg·png·webp)을 옆에 두면 레코드 가운데와 플레이리스트에 나와요. 예: `01 Thanks to - 김수현.jpg`
- 한 곡에 10MB 이하를 권장해요 (mp3 192kbps 기준 약 7분).
- ⚠️ 저장소가 공개라서, 여기 넣은 파일은 GitHub 에서 누구나 내려받을 수 있어요.
