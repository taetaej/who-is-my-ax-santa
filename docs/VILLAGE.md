# 마을 설계: ax-who-is-my-santa

상태: 초안 v0.1. 기준 문서는 `PRD.md`, `IA.md`다. 확정이 필요한 항목은 `[결정 필요]`, 구현 중 확인할 항목은 `[확인]`으로 표시한다.

## 1. 한 줄 요약

둥근 마을. 가운데에 큰 장식 트리가 서 있는 광장이 있고, 그 둘레를 기차 레일이 한 바퀴 돌며, 바깥 원에 14채의 집이 광장을 바라보고 늘어선다.

## 2. 에셋 실측 치수

Kenney Holiday Kit GLB의 크기를 직접 측정한 값이다. 단위는 월드 유닛이다.

| 에셋 | 크기 (가로 x 높이 x 깊이) | 비고 |
|---|---|---|
| cabin-wall | 1.0 x 1.0 x 0.3 | 모듈 기준. 1칸 = 1.0 |
| cabin-doorway | 1.0 x 1.0 x 0.4 | |
| cabin-roof / cabin-roof-snow | 1.3 x 1.45 x 1.4 | 지붕 1조각이 약 1.3 폭 |
| floor-wood / floor-stone | 1.0 x 0.08 x 1.0 | 바닥 1칸 |
| snow-flat / snow-flat-large | 1.9 x 0.1 x 1.5 / 3.1 x 0.1 x 2.4 | 눈 지면 타일 |
| gingerbread-man | 0.34 x 0.38 x 0.08 | 문 높이(1.0)에 비해 너무 작다 |
| trainset-rail-straight | 0.5 x 0.02 x 0.2 | |
| train-locomotive / train-wagon | 0.67 / 0.72 길이, 높이 0.43 / 0.31 | |
| present-a-cube | 0.45 x 0.3 x 0.45 | |
| tree-snow-a / tree-decorated-snow | 1.2 x 1.9 / 1.25 x 2.3 | |
| snowman | 1.1 x 1.06 x 0.69 | |
| reindeer / sled | 0.63 x 1.12 x 1.07 / 0.63 x 0.38 x 1.0 | |

스케일 결론:
- 진저브레드는 집에 비해 작아서 **약 2배**로 키운다. 문 높이 1.0 기준 캐릭터 높이 0.75 정도가 된다.
- 기차와 레일은 **같은 배율(1.5배 안팎)**로 키운다. 캐릭터를 태우는 연출은 하지 않으므로 기차는 집 크기에 비해 작은 장난감 느낌이어도 된다.
- 선물 상자는 개봉 연출에서 크게 키워 쓴다. 마을 장면에서는 원래 크기(0.45)로 쓴다.
- 이 값은 시작점이다. 실제 화면을 보며 조정한다. `[확인]`

## 3. 전체 배치

```
                 N
         [집]  [집]  [집]  [집]
      [집]                     [집]
                .--------.
     [집]      /  레일 링   \      [집]
              |  .------.  |
     [집]     |  | 광장 |  |     [집]
              |  | 트리 |  |
     [집]      \  '------'  /      [집]
                '--------'
      [집]                     [집]
         [집]  [집]  [집]  [집]
                 S
        (집 14채가 바깥 원, 문은 안쪽)
```

| 영역 | 반지름 | 내용 |
|---|---|---|
| 광장 | 0 ~ 4.5 | 큰 장식 트리, 게시판, 우체통, 벤치, 눈사람, 선물 낙하 지점 |
| 레일 링 | 약 6.5 | 기차가 도는 원형 레일. 광장과 집 사이 |
| 앞마당 | 7 ~ 8.5 | 집 앞 길. 각 집의 작은 소품이 놓인다 |
| 집 링 | 약 10 | 집 14채. 문이 중심을 향한다 |
| 외곽 | 11 ~ 16 | 눈 지면, 눈 쌓인 나무, 바위, 울타리. 가장자리는 눈더미와 나무로 가린다 |

계산 근거:
- 집 한 채의 폭을 3으로 보면 집 사이 간격을 포함해 중심 간 거리를 약 4.5로 둔다. 14채 x 4.5 = 63이고, 둘레가 63인 원의 반지름은 약 10이다.
- 레일 링 반지름 6.5의 둘레는 약 41이다. 직선 레일(길이 0.75, 1.5배 기준)을 약 54개 이어 붙이면 된다. 원형이라 코드에서 각도를 계산해 배치한다.

## 4. 집 설계

모든 집은 같은 틀에서 시작하고, 파츠로 변화를 준다.

- 기본 틀: 정면 3칸 x 측면 2칸의 벽 + 문 1개 + 창문 + 눈 쌓인 지붕. 조립 방식은 구현할 때 파츠를 맞춰 보며 확정한다. `[확인]`
- 변화 요소: 굴뚝, 도머 창, 창문 종류(a, b, c, 대형), 리스(화환) 유무, 울타리 유무, 지붕 눈 유무, 조명 줄 색(초록, 빨강, 컬러)
- 앞마당 소품 (집마다 하나씩): 선물 상자, 눈사람, 사탕지팡이, 작은 트리, 양말, 랜턴 등. 성격이나 취향에 맞춰 고를 수 있게 하면 프로필 카드와 연결된다. `[결정 필요]`
- 쿠키 캐릭터는 집 앞에 서 있다. 12명을 구분하는 색, 모자, 소품은 프로필에서 본인이 고른 값을 쓴다.

불 켜기 연출:
- 창문 재질에 빛(emissive)을 주거나 집 안에 점 조명을 둔다. 기본은 꺼진 상태이고 공개일에 켠다.
- Kenney 창문이 별도 재질로 분리돼 있는지 확인이 필요하다. 분리돼 있지 않으면 창 안쪽에 노란 평면을 따로 두는 방식으로 대체한다. `[확인]`

## 5. 집 배정

14채의 위치와 사람을 어떻게 연결할지 정해야 한다.

| 안 | 내용 | 비고 |
|---|---|---|
| 가나다순 | 이름 순서대로 시계 방향 배치 | 단순하고 찾기 쉽다 |
| 실제 좌석 순서 | 사무실 자리 순서를 반영 | 팀원들이 재미있어한다. 입력 정보가 필요하다 |
| 랜덤 | 시작 시 한 번 섞어 고정 | 무난하다 |

어떤 안이든 **마니또 매칭 순서와 집 위치는 서로 무관**해야 한다. 그래야 집 위치로 매칭을 추측할 수 없다. `[결정 필요]`

## 6. 광장과 특수 위치

| 오브젝트 | 위치 | 역할 | 에셋 |
|---|---|---|---|
| 큰 장식 트리 | 광장 중앙 | 마을 상징. 공개일에 마지막 점등 | tree-decorated-snow를 크게 확대 |
| 미션 게시판 | 광장 가장자리 | 클릭 시 미션 보드(H3) 열기 | 에셋 없음. 나무 판자 형태로 단순 조립 |
| 우체통 | 광장 가장자리 | 클릭 시 소개서 작성(H5) 열기 | 에셋 없음. 단순 도형 |
| 선물 낙하 지점 | 광장 중앙 근처 | 마니또 개봉(H1) 연출 | present-a/b |
| 눈사람, 벤치, 랜턴 | 광장 | 분위기 | snowman, bench, lantern |
| 순록 + 썰매 | 외곽 한쪽 | 마을 소품. 공개일 엔딩에 등장 가능 | reindeer, sled |
| 기차역 | 레일 위 한 지점 | 기차 정차 위치 | 레일, 열차, 벤치 |

게시판, 우체통은 클릭 진입 보조 경로다. IA 원칙대로 같은 기능이 메뉴 버튼에도 있어야 한다.

## 7. 공개일 기차 동선

공개 릴레이는 "대상 X → X의 산타 S → S의 산타 …" 순서로 14번 이어진다. 이 순서는 매칭에 따라 무작위이므로 집 사이 이동 거리가 매번 다르다.

규칙(제안):
1. 기차는 레일을 **항상 한 방향(시계 방향)**으로만 돈다. 구현이 단순하고 연출이 일정하다.
2. 현재 집에서 다음 집까지 레일을 따라 이동하고, 도착하면 멈춘다. 다음 집 앞에서 정차하고 해당 집 불이 켜진다.
3. 이동 거리가 길 때를 대비해 이동 시간 상한을 둔다. 예: 최대 5~6초로 속도를 거리에 맞춰 조절한다.
4. 기차는 처음 출발할 때 선물 상자를 싣고, 정차할 때마다 하차하는 연출을 한다. 선물 상자 모델은 present-a/b를 쓴다.
5. 마지막(14번째)에는 시작한 집으로 돌아와 마을 전체 불이 켜진다.

이동 시간 어림: 평균적으로 원의 절반 정도를 돌게 되고, 5초 상한이면 이동에만 최대 약 70초가 든다. 낭독과 추리 시간은 별도다.

`[결정 필요]` 이동 시간이 길면 지루할 수 있다. 줄이려면 "카메라가 기차를 따라간다 / 중간 생략하고 컷 전환한다 / 짧은 거리만 기차로 가고 먼 거리는 줌아웃 후 점프" 중에서 정해야 한다.

## 9. 분위기와 연출

- 낮: 따뜻한 연한 파랑 하늘과 흰 눈, 집 창문은 은은한 노랑. 홈과 일상 화면용이다.
- 밤: 남색 하늘, 집 창문은 꺼짐. 공개일 로비와 릴레이용이다. 불이 켜질 때 효과가 가장 잘 보인다.
- 낮밤 전환은 마니또 개봉(H1)과 공개일(R0) 진입 시점에 쓴다. 조명 색과 강도만 바꾸는 방식이다.
- 눈 입자는 파티클로 처리한다. 가벼운 효과를 위해 개수를 제한한다.
- 굴뚝 연기, 별 반짝임 같은 작은 움직임은 시간이 남을 때 추가한다.

## 10. 성능과 제작 방식

- 집 14채 x 파츠 약 30~40개 = 400~600개 메시. 같은 파츠는 인스턴싱하고, 집 한 채를 하나의 그룹으로 합쳐 두면 PC에서는 충분하다.
- 에셋은 GLB를 쓰고, 처음에 한 번만 불러 복제한다.
- 집 조립은 코드에서 `house(config)` 함수로 만든다. 설정 값(지붕, 창문, 장식, 소품)만 바꿔 14채를 생성한다.
- 마을 지형 배치는 설정 파일에 모아둔다. 위치, 방향, 소품을 코드 수정 없이 조정할 수 있다.
