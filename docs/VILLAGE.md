# 마을 설계: AX VILLAGE

상태: v0.2 (2026-11-19 갱신). 지금 구현된 마을 기준이다. 좌표와 크기의 원본은 `src/scene/world.ts` 이고, 이 문서와 다르면 코드가 맞다.

## 1. 한 줄 요약

둥근 눈 마을. 앞쪽 대문과 "AX VILLAGE 2026" 아치로 들어와, 가운데 큰 트리(메시지 트리)와 얼음 연못이 있는 광장에 모이고, 둘레의 놀이 장소로 디딤돌 길이 뻗는다. 집은 없다. 다같이 모이는 공간이다.

## 2. 전체 배치

화면 기준으로 아래(+z)가 입구, 위(-z)가 마을 안쪽이다. 카메라는 늘 아래쪽에서 비스듬히 내려다본다.

```
                      (안쪽)
            📮 AX 우편함   📜 연대기 전시   ☕ AX 카페
                         ⛪(오른쪽 끝 교회)
      🔥 불멍 회의실        🎄 큰 트리          ❄️ 눈밭
      (캐롤 스피커·앨범)    + 🧊 얼음 연못
                      📋 게시판   🧝 엘프
      🎂 파티 테이블                    🏆 어워즈 부스
                         │ 돌길
                   ┌─ AX VILLAGE 2026 ─┐  ← 아치 + 팀 명언 현판
             ──────┘     대문     └──────  ← 울타리
                         ● 시작 지점 (대문 밖)
                      (입구)
```

| 영역 | 반지름(중심에서) | 내용 |
|---|---|---|
| 트리 섬 | 0 ~ 1.9 | 큰 장식 트리 = 메시지 트리. 답 카드가 오너먼트로 걸린다 |
| 얼음 연못 | 1.9 ~ 3.5 | 들어가면 미끄러진다. 다리 2개 |
| 광장 돌길 | ~ 6.2 | 가로등 6개(리스), 트리에서 가로등으로 전구 줄, 벤치, 눈사람, 게시판, 엘프 |
| 장소 링 | 약 10 ~ 13 | 놀이 장소들. 광장에서 디딤돌 길과 지팡이 사탕으로 이어진다 |
| 울타리 | 17 | 전구가 달린 흰 울타리. 앞쪽에만 대문이 열려 있다 |
| 바깥 | 17 ~ | 눈 둔덕, 숲, 먼 산, 저녁 하늘과 별 |

### 3.1 입구
- 시작 지점은 **대문 밖 입구 길**. 들어오면 대문 → 아치 → 돌길 → 광장 순서로 마을에 들어선다.
- 아치: 지팡이 사탕 무늬 기둥, "AX VILLAGE ❄ 2026 ❄" 간판, 아래 현판에 팀 명언 "오늘 일 다 했으면, 내일 일 해라"(손글씨).
- 앞쪽에는 키 큰 물체를 두지 않는다. 카메라가 늘 아래쪽(입구 쪽)에 있어서 가리기 때문이다.

### 3.2 불멍 회의실 (캐롤)
- 모닥불 둘레 통나무 6개. 불 뒤편에 스피커 2대(우퍼가 박자에 맞춰 들썩)와 "김민지 · 2026 Christmas Carol" 앨범 입간판.
- 불 중심에서 3.6 안은 최대 볼륨, 7.5 밖은 안 들림. 모두 같은 소절이 나온다 (지금 시각 기준 재생 위치).
- 불가에 서 있거나 앉아 있으면 쿠키가 몸을 흔들고 박수 치듯 리듬을 탄다. 머리 위 "🎧 N명 같이 듣는 중".

### 3.3 2026 AX 연대기 전시
- 달마다 한 장씩, 마을 중심을 보며 호를 그리고 선 패널. 위에 "📜 2026 AX팀의 발자취: AI로 일하는 방식을 바꾸다" 현수막.
- 패널: 날짜, 이모지, 가벼운 한 줄, 원래 제목, 원문 기록. 글씨가 많으면 자동으로 줄어든다.
- 내용은 `src/timeline.ts` 한 곳. 달을 더하면 패널도 늘고 호가 넓어진다.

## 4. 캐릭터
- 진저브레드 쿠키. 팔다리를 코드로 흔들어 걷기·뛰기·인사(점프+손 흔들기)를 표현한다.
- 자세: 서기, 앉기(불멍), 눕기(눈밭 스노우엔젤). 핫초코 머그를 들 수 있다.
- 꾸미기: 반죽 3종, 머리 6종, 색 9가지, 소품 5종. 다른 사람에게 실시간으로 보인다.
- 이름표는 머리 위에, 카메라가 아주 가까우면 숨는다.

## 5. 카메라

| 상황 | 시점 |
|---|---|
| 로그인 전 / 🗺️ 전경(M) | 마을 위 높이 17, 거리 30에서 천천히 한 바퀴 |
| 평소 | 내 쿠키 뒤 위쪽(높이 7.5, 뒤로 9.5)에서 따라감 |
| 장소 앞 | 3장 표의 클로즈업 시점으로 부드럽게 바뀜 |

- 방향키는 화면 기준. 카메라가 돌아가 있어도 ↑ 는 화면 위쪽.
- 카메라와 내 쿠키 사이를 가리는 건물·나무는 반투명해진다.

## 6. 분위기
- 해 질 녘 저녁: 짙은 파랑 하늘, 노을빛 지평선, 별, 따뜻한 주황 조명. 블룸으로 불빛이 번진다.
- 전구: 트리, 가로등 사이 전구 줄, 울타리, 아치, 장소마다. 색깔별로 번갈아 깜빡인다.
- 눈이 내리고 땅 위에 반짝이가 흩날린다.

## 7. 제작 방식
- 외부 3D 모델 없이 코드로 만든 도형과 캔버스 질감(나무 판자, 벽돌, 회벽, 지붕널).
- 움직이지 않는 물체는 재질별로 합쳐 그린다(`Batch`).
- 간판 글씨는 캔버스로 그려 3D 판에 붙인다(`TextSign`). 다른 물체 뒤에 있으면 자연스럽게 가려진다.
- 떠 있는 이름표(장소 이름, 사람 이름)만 HTML 라벨이고, 가까워지면 숨는다.
