## 12/7 산타 배정

1. ⚙️ 운영 → **산타 배정 시작** 버튼. 14명이 한 줄로 이어지는 매칭이 이때 만들어져요.
2. **되돌릴 수 없어요.** 누르기 전에 14명 모두 입장했는지 확인하세요 (PIN 등록 안 한 사람도 매칭엔 들어가요).
3. 누르면 모두에게 "🎅 내가 챙길 사람이 정해졌어요" 알림이 뜨고, 산타 미션과 숨은 선물 찾기가 열려요.

## 12/15 어워즈 상장 만들기

1. ⚙️ 운영 → 어워즈 → **🤖 상장 쓰기 (전부)** 를 눌러요. Claude 가 사람마다 받은 키워드와 인터뷰 답을 모아(누가 했는지는 빼고) 상 이름과 문구를 써요. 1분쯤 걸려요.
2. 실패한 사람이 있으면 **없는 사람만** 을 한 번 더 눌러요. 직접 고친 뒤에 **전부** 를 누르면 고친 문구도 새로 써지니 조심해요.
3. ⚙️ 운영 → 어워즈에서 상 이름·문구를 읽어 보고 어색하면 ✏️ 고쳐요. 상장은 공개일에 열려요.

## 12/17 공개일 진행 순서

1. ⚙️ 운영 → **공개일 시작**: 관찰 리포트·추리노트가 잠기고 상장이 열려요. **되돌릴 수 없어요.**
2. 회식·미팅 화면에 사이트를 띄우고 ⚙️ 운영 → **🎬 공개일 발표 화면 열기**.
   - 첫 주인공을 고르면 "주인공 → 관찰 리포트 앞면(다같이 추리) → 주인공의 추리노트 → 카드 뒤집기(정체 공개)" 순서로, 밝혀진 산타가 다음 주인공이 돼요.
   - 정체 공개 단계에서 산타가 몰래 찍은 📸 사진이 카드 옆에 같이 나와요.
   - → / Space 다음, ← 이전, Esc 닫기.
3. 마지막 요약 화면에서 **🎄 메시지 트리 돌아보기 →** 로 이어서: 날짜별 질문과 모두의 답, ❤️ 베스트 카드 TOP 5, 개근상. (⚙️ 운영에서 따로 열 수도 있고, 미리 열어 봐도 괜찮아요)
4. 🏆 어워즈 부스에서 각자 상장 확인.
5. 🎀 숨은 선물 당첨자에게 선물 전달 (⚙️ 운영 → 숨은 선물에서 누가 무엇을 찾았는지 볼 수 있어요).

## 하지 말 것

- **⚙️ 운영 → 전체 초기화는 행사 중에 절대 누르지 않기.** 모든 기록·매칭·PIN 이 지워져요.
- 진행 단계 버튼(산타 배정 시작, 공개일 시작)은 **되돌릴 수 없어요.** 날짜를 확인하고 누르기.
- 매칭은 운영자도 볼 수 없게 만들어져 있어요. Neon 콘솔에서 `matches` 테이블을 열지 않기.
- 비밀 값(`DATABASE_URL`, `SESSION_SECRET`, `LIVEBLOCKS_SECRET_KEY`)은 `.env` 와 Vercel 환경변수에만.

## 자주 묻는 것

- **PIN 을 잊었어요** → ⚙️ 운영 → 진행 현황에서 그 사람 **PIN 초기화**. 다음 입장 때 새로 정해요.
- **5번 틀려서 잠겼어요** → 5분 뒤 다시 되거나, PIN 초기화.
- **질문이 이상해요 / 바꾸고 싶어요** → ⚙️ 운영 → 메시지 트리 질문에서 고치고 저장 (오늘 질문부터 바로 바뀌어요).
- **화면이 예전 그대로예요** → 새로고침. 배포는 `main` 에 올리면 1분 안에 자동으로 돼요.
- **휴대폰에서 썰매·눈싸움이 안 돼요** → 키보드 게임이라 PC 에서 해 주세요. 리포트·트리·일정은 휴대폰도 돼요.
