# IA: Who is my AX Santa?

상태: v0.2 (2026-11-19 갱신). 기준 문서는 `PRD.md`, 마을 배치는 `VILLAGE.md`. 아직 만들지 않은 화면은 `(예정)`.

## 1. 설계 원칙

- **마을이 곧 메뉴다.** 3D 마을 씬 하나를 계속 켜 두고, 기능은 장소로 찾아가 **E** 를 누르면 2D 창이 열린다.
- 같은 기능은 **아래 메뉴(dock)** 에서도 바로 열 수 있다. 장소를 못 찾아도 막히지 않게.
- 폼과 긴 글은 2D 창(React)으로 만든다. 3D 안에서 폼을 직접 만들지 않는다.
- 장소에 다가가면 카메라가 그 장면을 바라보는 **클로즈업 시점**으로 부드럽게 바뀐다.

| 등급 | 구성 | 대상 |
|---|---|---|
| A. 3D 연출 | 3D 씬이 주인공 | 첫 화면 회전, 전경 보기, 장소 클로즈업, 연대기 전시, 공개일(예정) |
| B. 3D + 2D 창 | 마을 위에 창이 열린다 | 로그인, 꾸미기, 마니또, 소개서, 메시지 트리, 어워즈, 엘프 대화 |
| C. 2D 위주 | 일반 웹 UI | 운영 화면 |

## 2. 전체 구조

```
입장
 ├─ G1 첫 화면: 마을 위를 천천히 도는 전경 + 로그인 창
 ├─ G2 로그인 (이름 + PIN)
 ├─ G3 PIN 최초 등록
 └─ G4 쿠키 꾸미기 (처음 들어올 때 1번, 필수)
마을 (모든 단계 공통)
 ├─ H0 마을: 대문 밖 입구 길에서 시작 → 아치 → 광장
 ├─ H1 🎁 나의 마니또 (ACTIVE 부터. 처음엔 선물 상자 열기)
 ├─ H2 💌 마니또 소개서 (📮 AX 우편함)
 ├─ H3 🎄 메시지 트리 (광장 큰 트리)
 ├─ H4 🏆 AX 어워즈: 동료 키워드 주기 (어워즈 부스)
 ├─ H5 🧝 엘프 대화 (광장)
 ├─ H6 ✏️ 내 프로필 · 🎨 꾸미기
 ├─ H7 🗺️ 전경 보기 (M)
 └─ 장소 놀이: 🔥 불멍 회의실(캐롤) · ☕ AX 카페 · ❄️ 눈밭 · 🎂 파티 테이블 · 📜 연대기 전시
공개일 (REVEAL)
 ├─ R0 어워즈 결과 (구현됨)
 └─ R1~R4 공개 프레젠테이션 (예정)
운영자
 └─ A1 ⚙️ 운영: 진행 현황 · 메시지 트리 질문 · 어워즈
```

## 3. 화면 목록

### 3.1 입장

| ID | 화면 | 등급 | 내용 |
|---|---|---|---|
| G1 | 첫 화면 | A | 해 질 녘 마을 위를 카메라가 천천히 돈다. 제목 "Who is my AX Santa?" |
| G2 | 로그인 | B | 14명 이름 선택 + PIN 4자리. 5번 틀리면 5분 잠금 |
| G3 | PIN 등록 | B | 처음이거나 운영자가 초기화한 사람 |
| G4 | 쿠키 꾸미기 | B | 반죽·머리·색·목도리·소품. 빙글 도는 미리보기, 🎲 아무거나. "이대로 마을에 들어가기" |

입장할 때마다 PIN 을 묻는다. 다시 오면 지난번 이름이 골라져 있어 PIN 4자리만 넣으면 되고("○○님이 아니에요"로 다른 이름 선택), 첫 화면의 마을 전경도 매번 보게 된다. 같은 탭에서 새로고침하면 그대로 들어가 있고, 탭이나 브라우저를 닫았다 열면 다시 묻는다.

### 3.2 마을

| ID | 화면 | 진입 | 내용 |
|---|---|---|---|
| H0 | 마을 | 로그인 후 | 방향키 이동, Shift 달리기, Space 인사, E 상호작용. 실시간으로 접속한 사람이 보인다 (왼쪽 위 "지금 마을에 N명") |
| H1 | 나의 마니또 | 🎁 메뉴 · 📋 마니또 게시판 · 엘프 | READY: "아직 정해지지 않았어요". ACTIVE: 선물 상자 → 이름·프로필 카드 |
| H2 | 마니또 소개서 | 💌 메뉴 · 📮 AX 우편함 · 엘프 | 6문항 폼 + 카드 미리보기(앞면 낭독/뒷면 정체 공개). 임시저장·제출 |
| H3 | 메시지 트리 | 🎄 메뉴 · 광장 큰 트리 · 엘프 | 오늘의 질문, 한 줄 걸기·고치기·떼기, ❤️, ‹ › 지난 날짜 |
| H4 | 동료 키워드 주기 | 🏆 메뉴 · 어워즈 부스 · 엘프 | 13명 이름 버튼 → 사람마다 칩 20개 중 1~3개 + 직접 쓰기. 고르는 즉시 저장, n/13 진행 표시. 공개일엔 상장 화면으로 바뀐다 |
| H5 | 엘프 대화 | 광장 🧝 엘프 | 남은 할 일을 하나씩 잔소리 + 바로 가기 버튼, 마을 팁. 할 일이 남으면 머리 위 ❗ |
| H6 | 프로필 · 꾸미기 | ✏️ · 🎨 메뉴 | 프로필 4항목 / 꾸미기 다시 하기 |
| H7 | 전경 보기 | 🗺️ 메뉴 · M | 마을 위를 천천히 돌며 전체를 본다. 움직일 수 있고 방향키는 화면 기준. M·Esc 로 끈다 |

장소 놀이 (창 없이 마을 안에서):

| 장소 | E 를 누르면 | 시점 |
|---|---|---|
| 🔥 불멍 회의실 | 통나무에 앉기. 캐롤이 가까울수록 크게, 다같이 리듬 | 자리 뒤에서 불을 바라봄 |
| ☕ AX 카페 | 핫초코 받아 들기 | 카페 정면 |
| ❄️ 눈밭 | 눕기(스노우엔젤) | 위에서 내려다봄 |
| 🎂 파티 테이블 | 케이크 한 조각 (말풍선) | 케이크 클로즈업 |
| 📜 연대기 전시 | (걸어가며 읽기) | 패널 정면으로 낮게 |

### 3.3 공개일 (REVEAL)

|---|---|---|---|

### 3.4 운영자 (A1 ⚙️ 운영, 신지아만)

| 탭 | 내용 |
|---|---|
| 진행 현황 | 현재 단계와 전환 버튼(되돌릴 수 없음 확인), 이름별 PIN·프로필·상자 개봉·소개서 제출 여부, PIN 초기화 |
| 메시지 트리 질문 | 한 줄에 하나씩 질문 목록, 첫 질문 날짜, 날짜별 미리보기 |
| 어워즈 | 사람마다 키워드를 준 동료 수 n/13, 칩 목록 (누가 무엇을 줬는지는 못 봄) |

운영 화면에는 매칭과 남의 내용이 나오지 않는다. 소개서 제출 여부는 "쓴 사람" 기준이라 대상이 드러나지 않는다.

## 4. 아래 메뉴 (dock)

`🍪 이름` · `🎁 나의 마니또` · `💌 소개서 (상태)` · `🎄 메시지 트리` · `🏆 어워즈 (n/13)` · `✏️ 내 프로필` · `⚙️ 운영(운영자만)` · `🗺️ 전경` · `🎨 꾸미기` · `로그아웃`
