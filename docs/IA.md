# IA: Who is my AX Santa?

상태: v0.3 (2026-11-25 갱신). 기준 문서는 `PRD.md`, 마을 배치는 `VILLAGE.md`. 아직 만들지 않은 화면은 `(예정)`.

## 1. 설계 원칙

- **마을이 곧 메뉴다.** 3D 마을 씬 하나를 계속 켜 두고, 기능은 장소로 찾아가 **E** 를 누르면 2D 창이 열린다.
- 같은 기능은 **아래 메뉴(dock)** 에서도 바로 열 수 있다. 장소를 못 찾아도 막히지 않게.
- 오늘 무엇을 해야 하는지는 **왼쪽 위 상태 카드**와 📅 일정 창이 알려 준다. 날짜는 `src/schedule.ts` 한 곳.
- 폼과 긴 글은 2D 창(React)으로 만든다. 3D 안에서 폼을 직접 만들지 않는다.
- 장소에 다가가면 카메라가 그 장면을 바라보는 **클로즈업 시점**으로 부드럽게 바뀐다.

| 등급 | 구성 | 대상 |
|---|---|---|
| A. 3D 연출 | 3D 씬이 주인공 | 첫 화면 회전, 전경 보기, 장소 클로즈업, 연대기 전시, 놀이(눈싸움·썰매·눈굴리기·로켓) |
| B. 3D + 2D 창 | 마을 위에 창이 열린다 | 로그인, 꾸미기, 일정, 내가 챙길 사람, 관찰 리포트, 추리노트, 메시지 트리, 어워즈, 엘프 대화 |
| C. 2D 위주 | 일반 웹 UI | 운영 화면, 공개일 발표 화면, 메시지 트리 돌아보기 |

창은 밝은 유리 패널에 빨간 이름표 제목이다. HUD 아이콘은 Phosphor 아이콘을 오너먼트 모양에 담는다.

## 3. 화면 목록

### 3.1 입장

| ID | 화면 | 등급 | 내용 |
|---|---|---|---|
| G1 | 첫 화면 | A | 우주에 뜬 행성 섬 위를 카메라가 천천히 돈다. 제목 "Who is my AX Santa?" |
| G2 | 로그인 | B | 14명 이름 선택 + PIN 4자리. 5번 틀리면 5분 잠금 |
| G3 | PIN 등록 | B | 처음이거나 운영자가 초기화한 사람 |
| G4 | 쿠키 꾸미기 | B | 반죽·머리·색·목도리·소품. 빙글 도는 미리보기, 🎲 아무거나. "이대로 마을에 들어가기" |

입장할 때마다 PIN 을 묻는다. 다시 오면 지난번 이름이 골라져 있어 PIN 4자리만 넣으면 되고("○○님이 아니에요"로 다른 이름 선택), 첫 화면의 마을 전경도 매번 보게 된다. 같은 탭에서 새로고침하면 그대로 들어가 있고, 탭이나 브라우저를 닫았다 열면 다시 묻는다.

운영 화면에는 매칭과 남의 내용이 나오지 않는다. 관찰 리포트 제출 여부는 "쓴 사람" 기준이라 대상이 드러나지 않는다.

## 4. 아래 메뉴 (dock)

오너먼트 아이콘 6개 + 더보기:

`일정` · `챙길 사람` · `관찰 리포트 (상태)` · `추리노트 (상태)` · `메시지 트리` · `어워즈 (n/13, 공개일엔 숨김)` · `☰ 더보기`

☰ 더보기 (밖을 누르거나 Esc 로 닫힘): `🍪 이름` · `내 프로필` · `쿠키 꾸미기` · `마을 전경 보기` · `조작법 보기` · `운영(운영자만)` · `나가기`

## 6. 미결정 사항
- 모바일: 들어갈 수는 있지만 키보드 놀이(이동·눈싸움·썰매)는 못 한다. 모바일 조작은 만들지 않는 쪽으로 가정.
- 공개 화면 조작은 정해졌다: 운영자가 띄우고 → · Space 로 넘긴다. 첫 주인공은 이름 버튼 또는 🎲.
