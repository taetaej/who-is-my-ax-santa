# PRD: Who is my AX Santa?

상태: v0.2 (2026-11-19 갱신). 일정은 잠정 확정. 미확정 항목은 `[미정]`, 아직 만들지 않은 기능은 `(예정)`으로 표시한다.

## 1. 개요

### 1.1 목적
AX팀 연말 마니또를 단순 선물 교환이 아닌 "관찰 → 기록(산타의 관찰 리포트) → 맞춤 선물 증정"의 흐름으로 설계한다. 팀원들이 한 마을에 모여 놀면서 마니또를 진행하는 전용 웹 서비스다.

### 1.2 참여 대상
AX팀 14명. 운영자(신지아)도 플레이어로 참여한다.

참여자: 김수현, 김민지, 김승형, 박희덕, 서보라, 신지아, 원전환, 정문원, 조이레, 최윤지, 구경민, 정재은, 오수정, 최지은

### 1.3 핵심 컨셉
- 연애 리얼리티 "환승연애 X소개서" 포맷을 차용한 산타의 관찰 리포트
- 온라인 사우나·온라인 절처럼 **다같이 한 공간에 모여 가볍게 상호작용하는** 3D 마을
- 세계관: 해 질 녘 눈 내리는 "AX VILLAGE". 주민은 진저브레드 쿠키이고, 각자 꾸민 쿠키로 접속해 방향키로 돌아다닌다.
- AX팀 색: 팀 명언("오늘 일 다 했으면, 내일 일 해라"), AX 카페·불멍 회의실·AX 우편함, 2026 AX 연대기, AX 어워즈, 팀원들이 직접 만든 캐롤 (📻 AX 캐롤 라디오)

### 1.3.1 호칭 (화면 문구는 이것만 쓴다)
| 호칭 | 뜻 | 화면 예시 |
|---|---|---|
| 🎅 **산타** | 몰래 챙겨 주는 사람. 모두가 누군가의 산타다 | "🎅 나는 이분의 산타예요", "산타의 관찰 리포트" |
| **내가 챙길 사람** | 내가 산타가 되어 줄 사람 (원래 말로 마니띠) | "🎅 내가 챙길 사람", "내가 챙길 사람이 정해졌어요" |
| **내 산타** | 나를 몰래 챙기는 사람. 공개일(12/17)에 밝혀진다 = 제목 "Who is my AX Santa?" | "○○ 님의 산타는…" |

- "마니또"는 행사(게임) 이름을 말할 때만 쓰고, 사람을 가리키는 말로는 쓰지 않는다 (마니또·마니띠가 거꾸로 쓰여 헷갈리기 때문).
- 코드와 DB 는 예전 이름(manito, letter)을 그대로 쓴다. 화면 문구만 바꿨다.

### 1.4 이벤트 일정 (잠정 확정)
| 항목 | 내용 |
|---|---|
| 준비 (READY) | ~12/6. PIN 등록, 쿠키 꾸미기, 프로필 작성 |
| 시작 (ACTIVE) | **12/7 (월)** 운영자가 "산타 배정 시작" → 매칭 생성 |
| 진행 기간 | 12/7 ~ **12/16** (10일). 관찰, 관찰 리포트 작성, 메시지 트리, 동료 키워드 주기 |
| 공개일 (REVEAL) | **12/17** 운영자가 "공개일 시작" → 관찰 리포트 잠금, 정체 공개, 어워즈(키워드 상) 발표 |
| 선물 예산 | 2만원 이하 |

### 1.5 성공 기준
- 14명 전원이 챙길 사람을 확인하고 관찰 리포트를 제출한다.
- 공개일에 14명 전원이 끊김 없이 공개를 마친다.
- 공개 전에는 운영자를 포함한 누구도 매칭 정보를 알 수 없다.
- 진행 기간 동안 팀원들이 마을에 자주 들어와 메시지 트리와 어워즈에 참여한다.

## 4. 핵심 로직

### 4.1 매칭: 단일 순환
1. 14명 배열을 Fisher-Yates로 셔플한다.
2. `User[i] → User[i+1]`, `User[13] → User[0]`으로 연결한다. (산타 → 챙길 사람)

보장하는 것: 자기 자신 매칭 없음, 1:1 맞교환(A↔B) 없음, 공개 릴레이가 한 바퀴로 이어진다.

### 4.2 블라인드 어드민
- 어떤 화면과 API에서도 "누가 누구의 산타인가"를 운영자에게 노출하지 않는다.
- 매칭은 READY → ACTIVE 전환 때 서버에서 한 번만 만들고, 결과를 로그에 남기지 않는다.
- 한계: DB에 직접 접근하면 확인할 수 있다. "UI와 API 레벨 차단"까지를 보장하고, Neon 콘솔에서 `matches` 를 열지 않는 것은 규칙으로 지킨다.

### 4.3 데이터 노출 규칙
| 데이터 | 공개 전 | 공개일 이후 |
|---|---|---|
| 매칭 | 본인이 챙길 사람만 | 정체 공개(예정) |
| 관찰 리포트 | 쓴 사람만 | 전체 공개(예정) |
| 어워즈 키워드 | 내가 준 키워드만. 운영자도 사람별 "몇 명에게 줬는지"만 | 사람마다 상 이름과 받은 키워드 수. 누가 줬는지는 끝까지 비공개 |
| 메시지 트리 | 모두 이름과 함께 | 동일 |

## 5. 기능 요구사항

### 5.1 인증 (구현됨)
- 이름 선택 + 4자리 PIN. 회원가입과 SSO는 없다. 최초 접속 시 PIN을 직접 등록한다.
- PIN은 scrypt 해시로만 저장한다. 5번 틀리면 5분 잠금.
- **입장할 때마다 PIN 을 묻는다.** 지난번 이름은 기억해 두고 PIN 4자리만 받는다. 같은 탭에서 새로고침하면 그대로 두고, 탭이나 브라우저를 닫았다 열면 다시 묻는다.
- 로그인은 서명한 httpOnly 세션 쿠키로, 브라우저를 닫으면 사라지고 켜 둬도 12시간이면 끝난다. PIN 분실 시 운영자가 초기화하면 기존 로그인이 모두 풀리고 새로 등록한다.

### 5.2 쿠키 꾸미기 · 프로필 (구현됨)
- 처음 들어오면 쿠키 꾸미기 창이 먼저 뜬다: 반죽 3종, 머리 6종(산타 모자·방울 비니·루돌프 뿔·왕관·귀마개·없음), 색, 목도리, 소품 5종. 언제든 🎨 꾸미기로 바꿀 수 있고 다른 사람에게 실시간으로 보인다.
- 프로필(나를 챙길 산타에게 보이는 정보): 좌석 위치, 선호 음료/간식, 스타일 키워드, 피하고 싶은 것.

### 5.3 내가 챙길 사람 (구현됨)
- ACTIVE가 되면 "🎅 내가 챙길 사람이 정해졌어요" 알림이 뜨고, 확인하면 그 사람 이름과 프로필이 공개된다. 이미 연 뒤에는 바로 표시한다.

### 5.4 마을 활동 (구현됨)
| 장소 | 하는 일 |
|---|---|
| 🎄 메시지 트리 (광장 큰 트리) | 평일마다 바뀌는 "오늘의 질문"(주말은 금요일 질문이 이어짐, 8개)에 한 줄(140자) 답을 이름과 함께 건다. ❤️, 지난 날짜 보기. 질문 목록과 시작일은 운영자가 관리 |
| 🏆 AX 어워즈 | 나를 뺀 13명에게 키워드 칩 1~3개 + 직접 쓰기 1개. 가장 많이 받은 키워드가 그 사람의 상 (공동 1등이면 2관왕, 못 받으면 기본 상). 공개일 전까지 수정 가능 |
| 🔥 불멍 회의실 | 📻 AX 캐롤 라디오: 팀원들이 만든 캐롤이 차례로 흐르고 다같이 리듬을 탄다. 가까울수록 크게, 모두 같은 곡·같은 소절. 턴테이블 부스·전구 줄·스피커·불이 음악에 맞춰 반응 |
| ☕ AX 카페 | 핫초코를 받아 들고 다닌다 |
| ❄️ 눈밭 | 누워서 스노우엔젤(E), ☃️ 눈싸움(F): 과녁 눈사람·동료 맞히기, 점수 없이 재미로 |
| 🎂 AX 파티 테이블 | 3단 케이크 |
| 📜 2026 AX 연대기 | 올해 팀의 발자취를 달별 패널로 전시 |
| 🧝 AX 엘프 | 오늘 할 일(상자 개봉·메시지 트리·키워드·관찰 리포트)을 잔소리하고 마을을 안내. 숨은 선물 개수를 알려 주고, 12/14부터는 못 찾은 사람에게 위치 힌트 |
| 🎀 숨은 선물 (보물찾기) | 산타 배정 시작부터 마을 곳곳 46곳에 숨은 선물 (진짜 14 + 꽝 32, 힌트 없음). 진짜는 등수가 있다: 🥇 1등 1 · 🥈 2등 2 · 🥉 3등 4 · 🎁 4등 7 (어려운 자리일수록 높은 등수). 상자·양말·쿠키 통·꾸러미·트리 오너먼트·눈더미·얼음 속 등 장소에 맞는 모양이고 색도 주변에 섞여서, 진짜와 꽝을 겉보기로 구별할 수 없다. 아무것도 없는 위장 눈더미 20개도 섞여 있다. 왼쪽 위 "🎀 남은 선물"과 현황 창에서 등수별 남은 개수와 누가 몇 등을 찾았는지 모두 볼 수 있다. 눈더미·얼음은 E 3번으로 파낸다. 아주 가까이(1.5칸) 가야 살짝 반짝이고 "뭔가 반짝인다…?". **꽝**은 재밌는 한마디와 함께 열린 빈 상자로 남고 기회는 그대로. **진짜는 1인 1개**, 자리 하나는 먼저 연 한 사람만. 누가 찾으면 마을에 알림. 12/14부터 남은 진짜가 반짝이고 엘프가 위치 힌트. 어느 자리가 진짜이고 몇 등인지는 서버에만 (`server/treasure.ts`), 위치·모양과 등수별 선물 이름은 `src/treasure.ts`. 실물 선물은 운영자가 전달 |

공통: Space 인사, 🗺️ 전경 보기(M), 장소별 클로즈업 시점, 실시간 접속자 표시.

### 5.5 산타의 관찰 리포트 (구현됨, 📮 AX 우편함)
ACTIVE 동안 작성·수정할 수 있고, 입력하면 카드 미리보기(앞면/뒷면)로 렌더링된다.

| # | 문항 | 형식 | 카드 |
|---|---|---|---|
| 1 | 해시태그 3개 | `#키워드` x 3 | 앞면 |
| 2 | 첫인상 vs 몰래 지켜본 현인상 | "처음엔 [ ]한 분인 줄 알았는데, 산타가 되어 몰래 관찰해 보니 의외로 [ ]한 면이 있었습니다." | 앞면 |
| 3 | 산타가 스캔한 캐릭터 스탯 | 능력치 이름 + 0~100% x 3. 추천 칩(업무 몰입도·카페인 의존도·칼퇴 본능·리액션 온도·간식 레이더·점심 메뉴 결정력)을 누르면 빈칸이 채워진다 | 앞면 |
| 4 | 드라마/영화 주인공이라면? + 테마 BGM | 장르 + 노래 + 짧은 이유(선택) | 앞면 |
| 5 | 산타의 비밀 관찰 TMI & 맞춤 선물 | "몰래 관찰해 보니 [ ] 모습이 눈에 띄더라고요. 그래서 이 선물을 준비했어요!" (받침에 상관없이 이어지게) + 선물명 (2만원 이하) | TMI 앞면, 선물 뒷면 |
| 6 | 산타의 은밀한 정체 힌트 1줄 | 공개 직전 다같이 추리할 단서 | 앞면 |

- 임시저장과 제출을 구분한다. 제출하려면 모든 문항이 차 있어야 한다 (BGM 이유만 선택). 제출 후에도 공개일 전까지 고칠 수 있다.
- 운영자는 "쓴 사람" 기준 제출 여부만 본다.
- 미제출자: 임시저장한 내용이 있으면 그대로 띄우고, 아예 없으면 발표 화면에 "관찰 리포트가 비어 있어요… 직접 말로 소개해 주세요"가 나온다.

### 5.5.1 🔍 내 산타 추리노트 (구현됨, 아래 메뉴 🔍)
관찰 리포트가 "산타가 나를 어떻게 지켜봤는지"라면, 추리노트는 "내가 산타의 흔적을 어떻게 눈치챘는지"다. 공개일 더블 리빌 2단계에서 열린다.

| # | 문항 | 형식 |
|---|---|---|
| 1 | 🎯 내 산타는 바로…! | 나를 뺀 13명 중 1명 + 확신도 슬라이더 10~100% |
| 2 | 지목한 결정적 이유 | "제가 ○○님을 제 산타로 지목한 결정적 이유는 [ ] 때문이에요!" |
| 3 | 결정적 목격담 (선택) | 한 줄 |
| 4 | To. 내 산타 | 한마디 (예시 칩) |

- 진행 기간(ACTIVE)에 쓰고 몇 번이든 고친다. 1·2·4가 차면 "완성". 공개일에 잠긴다.
- 공개일 전에는 쓴 본인만 본다. 운영자는 완성 여부만 본다. 엘프가 안 쓴 사람에게 잔소리한다.

### 5.6 공개일 더블 리빌 발표 화면 (구현됨, ⚙️ 운영 → 진행 현황 → 🎬)
회식이나 팀 미팅 화면에 띄워 14명이 함께 보는 연출 화면이다. 공개일(REVEAL)부터 운영자만 연다. 짝은 이 화면에서 처음 보인다.
1. 첫 주인공을 고른다 (이름 버튼 또는 🎲 아무나).
2. 주인공 한 명마다 4단계 (→ · Space 다음, ← 이전, Esc 닫기):
   1. 주인공 소개
   2. 관찰 리포트 앞면: 산타 이름 없이 띄우고 다같이 추리
   3. 주인공의 추리노트: "내 산타는 ○○님! 확신도 95%" + 이유·목격담·한마디. 지목한 사람이 사실 주인공 본인이 챙기던 사람이면 "😂 그분은 당신이 챙기던 사람이에요!" (한 줄 순환이라 그 사람은 절대 산타일 수 없다)
   4. 카드 뒤집기: 산타 이름과 선물 공개 + 🎯 추리 성공 / 🕵️ 완전범죄 성공
3. 릴레이: 밝혀진 산타가 다음 주인공. 14명 한 바퀴면 끝.
4. 마무리: 명탐정·완전범죄 산타 명단, 산타 → 챙긴 사람 · 선물 전체 목록. 이어서 🏆 어워즈 부스에서 상장 공개.

### 5.7 운영자 기능 (구현됨, ⚙️ 운영)
- 단계 전환 (READY → ACTIVE → REVEAL, 확인 팝업)
- 진행 현황: 이름별 PIN 등록, 프로필, 상자 개봉, 관찰 리포트 제출 여부 (매칭은 표시하지 않음)
- PIN 초기화
- 메시지 트리 질문 목록과 첫 질문 날짜, 날짜별 미리보기
- 어워즈: 사람마다 키워드를 준 동료 수 (내용은 보지 않음)

## 6. 비기능 요구사항
- 디자인: 해 질 녘 크리스마스 저녁의 3D 마을. 전구·리스·지팡이 사탕·별, 블룸 조명.
- 3D: 외부 모델 없이 코드로 만든 로우폴리. 폼과 창은 2D UI를 3D 위에 얹는다.
- 디바이스: PC 브라우저 중심. 모바일은 지원하지 않는다. 공개 모드는 대형 화면도 고려한다.
- 규모: 동시 접속 14명 내외.
- 기술 스택: README 의 "기술 스택" 참고 (Vite + React + R3F, Hono, Neon, Liveblocks, Vercel).
